# 📝 Changelog - Luis Eden Paisagismo

## [1.0.0] - 2024-01-15

### ✨ Novidades
- **Dashboard** - Visão geral com gráficos de vendas e desempenho
- **Catálogo** - Gerenciamento completo de plantas e flores
- **Vendas** - Sistema de PDV com histórico de transações
- **Orçamentos** - Construtor de orçamentos com cálculo automático
- **Manutenção** - Agendamento com visualização em calendário
- **Fluxo de Caixa** - Controle financeiro com relatórios
- **Fornecedores** - Gestão de fornecedores e cotações
- **Clientes** - Cadastro e histórico de clientes
- **Usuários** - Gerenciamento de usuários e permissões
- **Importação** - Suporte para importar dados via Excel
- **Autenticação** - Sistema de login seguro
- **Responsividade** - Interface adaptada para mobile e desktop

### 🎨 Interface
- Design moderno com paleta de cores verde e dourado
- Topbar com atalhos rápidos
- Sidebar com navegação intuitiva
- Modais para operações principais
- Ícones FontAwesome para melhor UX
