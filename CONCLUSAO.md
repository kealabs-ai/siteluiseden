## 🚀 Como Usar

### Para Usuários
```
1. Clique no ícone [?] na topbar
2. Escolha uma aba:
   - Início Rápido: Primeiros passos
   - Módulos: Descrição de cada módulo
   - FAQ: Perguntas frequentes
   - Suporte: Contato e recursos
3. Leia as informações
4. Clique em "Fechar"
```

### Para Desenvolvedores
```bash
# Instalar
cd app
npm install

# Executar
npm run dev

# Acessar
http://localhost:5173

# Customizar
Edite: app/src/components/HelpModal.jsx
```

### Para Administradores
```
1. Distribua MANUAL.md aos usuários
2. Mantenha CHANGELOG.md atualizado
3. Use HELP_CENTER.md para treinamento
4. Monitore VERSION_INFO.md
```
